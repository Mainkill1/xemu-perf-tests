# Audio fixtures

These files are deterministic test data generated by
`utils/generate_audio_fixtures.py`. They contain no third-party recordings
and are covered by the repository's Unlicense/public-domain dedication.

The checked-in payload is intentionally small. The XISO should use these files
for format correctness, loader/package validation, ADPCM known-answer checks,
and audible smoke tests. Large multi-voice stress workloads should synthesize or
repeat deterministic data at runtime instead of adding large recordings to Git.

## Audible WAV files

- `pcm_s16_stereo_48k_multitone.wav`: different prime-frequency triangle
  tones in left and right channels. Useful for channel routing and AC'97 sanity.
- `pcm_s16_mono_44k1_impulse.wav`: impulse train at 44.1 kHz. Useful for
  resampling, boundary, and dropout inspection.
- `pcm_s16_stereo_48k_lfsr.wav`: deterministic wide-spectrum noise. Useful
  for obvious corruption/dropout detection.

## Raw VP fixtures

The `raw/` files provide exact byte layouts for S16, S24-in-B32, S32, and
IMA/Xbox ADPCM paths. ADPCM fixtures include decoded S16 goldens so the codec
can be checked without relying on captured speaker output. U8 data is generated
at runtime from the same deterministic integer signal source; this keeps the U8
path exact without depending on a fragile high-byte binary resource.

The ADPCM block format yields 65 decoded frames per channel. The pinned xemu
source currently uses a 64-frame block-position constant with a FIXME. Tests
should keep those two facts separate: the 65-frame golden validates the codec
fixture, while a VP test should explicitly characterize what the emulated voice
engine consumes.

## Why there is no MIDI

MIDI is not an audio sample format and does not directly exercise the MCPX
voice decode/mix hot paths. A MIDI fixture becomes useful only if this project
adds a DirectMusic/XACT/sequencer-specific test family. Adding it to the current
VP/GP/EP suite would increase surface area without proving the paths this PR is
trying to measure.

Regenerate the assets with:

```bash
python3 utils/generate_audio_fixtures.py
```

Verify the checked-in copies with:

```bash
python3 utils/generate_audio_fixtures.py --check
```
